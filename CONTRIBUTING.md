# Contributing

## Branching
- Branch names come from the Signal issue. Use the branch name Signal gives
  you when you start work on the issue (e.g. `eng-2-add-a-contributing-file-to-the-test-repo`).
- Create the branch from an up-to-date `main`.

## Pull requests
1. Make focused commits with clear messages.
2. Push your branch to `origin`.
3. Open a pull request against `main` and link the Signal issue
   (the branch name does this automatically).
4. Request a review. Do not merge your own pull request.
